# Sales Performance Dashboard - Power BI

# Project Overview
This project demonstrates the development of an interactive Sales Performance Dashboard using Microsoft Power BI.
The project was completed as part of my Power BI training using a dataset provided through a Udemy course.
The original dataset was already cleaned. My work focused on developing calculated columns, DAX measures, data analysis and dashboard visualisation.

## Business Questions
The dashboard was developed to analyse key aspects of sales and profitability performance including: 

- What are the overall sales and profit levels?
- Which products generate the highest sales?
- Which products generate the highest profit?
- How does profitability differ  across regions?
- How do sales change over time?
- Which products and regions are contributing most to overall performance?

## Key Performance Indicators 
The dashboard includes the following key metrics:
- Total Sales 
- Total Profit
- Average Profit Margin
- Sales by Product
- Profit by Product
- Profit Margin by Region
- Monthly Sales Performance
